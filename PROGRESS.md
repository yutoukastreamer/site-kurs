## 2026-06-09 — Интеграция отслеживания форм с Calltouch

**Задача:** передавать заявки с сайта kurs-gsi.ru в Calltouch (форма обратной
связи + кнопки «Получить предложение»).

**Что сделано:**
- Создан файл `public/calltouch-forms.js` — вся логика отслеживания.
- В `index.html` перед `</body>` подключён скрипт:
  `<script defer src="/calltouch-forms.js"></script>`.

**Как работает:**
- Слушатели висят на `document` (делегирование) — переживают перерисовку React
  и переходы между страницами SPA.
- **Форма обратной связи** (встроенная форма Bitrix24): перехватывается событие
  `submit`, поля имя/телефон/email читаются по эвристике (`type`/`name`/
  `placeholder`), телефон нормализуется к виду `79000000000`.
- **Кнопки «Получить предложение»** (это якорные ссылки на `#contact`, не сабмит):
  при клике запоминается продукт по URL (`/bulldozer`, `/excavator`, `/grader`),
  и его название подставляется в `subject`/`comment` при отправке формы.
- `sessionId` берётся через `window.ct('calltracking_params','4xv0727u')`.
- UTM-метки (`utm_source/medium/campaign/content/term`) собираются из URL.
- Отправка — чистый `fetch` POST на REST API Calltouch
  `https://api.calltouch.ru/calls-service/RestAPI/requests/82582/register/`.
- Логирование каждого шага в консоль (префикс `[Calltouch]`) + обработка ошибок.

**ID (подставлены в файл):** site_id `82582`, mod_id `4xv0727u`.

**Проверено в браузере (сквозной тест с перехватом fetch):**
- [x] Скрипт грузится и инициализируется (`[Calltouch] … инициализирован.`).
- [x] Формы Bitrix24 рендерятся, поля имеют `name="name"/"email"/"phone"` —
      эвристика `scrapeForm` их корректно читает.
- [x] Нормализация телефона: `8 (912) 345-67-89` → `79123456789`.
- [x] Клик «Получить предложение» → продукт уходит в `subject`/`comment`.
- [x] POST уходит на `…/requests/82582/register/` с правильным payload.
